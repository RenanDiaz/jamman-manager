# Contributing

Thanks for your interest in contributing to JamMan Manager.

## Issues

- Reports of bugs, problems, and flaws are welcome.
- Documentation improvements are welcome as well.
- If you have a question or need help, please use the discussions section.

## Pull Requests

- Follow the [README.md](README.md) to set up the project. It also describes the structure and the available commands.
- Before proposing a big change, open an issue to discuss it first.
- Prefer native platform features and avoid adding third-party dependencies without a good reason.
- Run lint, typecheck and tests locally before opening a PR (the Husky hooks run most of them). If you can't run the tests locally, open the PR as a draft.
